Privacy policy

vidforge is used only by the owner of the Late Night History TV YouTube channel to manage that channel. It is not offered to other users.

With the owner's authorization it uses the YouTube Data API and YouTube Analytics API to upload videos, set thumbnails, captions and playlists, post comments, and read the channel's own analytics. The OAuth token is stored only as an encrypted GitHub Actions secret. No personal data of viewers or other users is collected, sold or shared.

vidforge's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.
